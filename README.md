# OpenCosy 浏览器

## 项目简介

OpenCosy 浏览器是热土工作室基于 [Cosy浏览器](https://cosy.rtstu.com) 制作的**开源项目**。

Cosy浏览器是一款简洁、快速的多标签页浏览器，为用户提供舒适的浏览体验。OpenCosy 项目延续了这一理念，致力于为用户提供一个轻量、高效且安全的开源浏览器解决方案。

## 主要特性

- **多标签页浏览**：支持同时打开多个网页，便捷的标签页管理
- **简洁界面**：清新简洁的界面设计，带来舒适的视觉体验
- **快速响应**：基于 Chromium 内核，提供流畅的网页加载速度
- **个性化设置**：支持主题颜色定制和搜索引挚配置
- **下载管理**：内置下载管理功能，方便管理下载文件
- **插件扩展**：支持插件扩展功能（实验性）

## 技术架构

- **框架**：Electron
- **内核**：Chromium
- **语言**：JavaScript、HTML、CSS

## 版本信息

- 当前版本：1.0.0
- 许可证：Apache 2.0

## 获取与使用

### 安装使用

1. 下载最新的发布版本
2. 运行安装程序或直接运行可执行文件
3. 开始使用 OpenCosy 浏览器
注意：
- 本项目移除了很多热土工作室私有功能，如不希望自己定制功能，建议使用 Cosy 浏览器。

### 从源码构建

```bash
# 克隆项目
git clone <repository-url>

# 安装依赖
npm install

# 运行开发版本
npm run dev

# 构建生产版本
npm run build:win
```
