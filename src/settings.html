个性化设置

选择浏览器的主题颜色，将应用于整个浏览器界面

开启深色模式以减少眼睛疲劳，适合夜间浏览

后台标签闲置 30 分钟后自动释放其内存，点回时重新加载；正在播放声音或被录屏共享的标签不会休眠

每次关闭浏览器后清空缓存、Cookie、站点存储、历史与下载记录，且不恢复上次标签页；适合公用电脑或注重隐私的场景

仍有多个标签页打开时，点关闭按钮先弹确认，避免一次误关整窗丢失所有页面

屏蔽常见分析、广告与跨站追踪请求（脚本 / 图片 / 请求等），不影响你直接打开任何网站；右下角盾牌显示本次拦截数

网页在跨站（第三方）上下文试图种下的 Cookie 会被直接剥离，阻断广告商跨站追踪和部分 CSRF；不影响你直接登录的网站，可在“安全中心 → Cookie 加固”查看处理记录

没有 SameSite 的 Cookie 自动补 SameSite=Lax（对齐现代 Chrome 默认）；SameSite=None 缺 Secure 时降级为 Lax；剥离 http 页面的 Secure Cookie 和不合法的 __Host-/__Secure- 前缀 Cookie

防止你打开的公网网页偷偷请求路由器后台、本机服务或云服务器元数据（169.254.169.254），阻断 CSRF 打内网与云凭据窃取；不影响你直接访问内网，也不影响内网页面之间的正常调用

允许视频网站调用画中画（Picture-in-Picture）在离开页面后用悬浮小窗继续播放；关闭后通过 Permissions-Policy 全局禁用该能力，可避免视频站点借悬浮窗持续跟踪播放

自动剥离完整浏览器版本、操作系统小版本、CPU 架构/位数、设备型号等高熵 Sec-CH-UA-* 请求头，只保留兼容性所需的低熵基础头，降低被跨站指纹识别的概率（不影响页面渲染与兼容性）

移除 Sec-Browsing-Topics（兴趣主题）与 Attribution-Reporting-*（广告归因）等请求头，阻止广告商跨站追踪你的浏览主题与转化链

阻止页面用 <a ping> 或带 Ping-To 的请求在你点击链接时静默向第三方上报点击；仅取消打点请求，不影响正常跳转

移除响应头里的 Accept-CH 与会触发带新头重试的 Critical-CH，阻止站点“订阅”高熵客户端提示并放大指纹采集

严格：WebRTC 只走默认公网接口，不暴露内网/真实公网 IP（防穿透 VPN，推荐）；均衡：允许 mDNS 混淆的内网候选，兼容部分 P2P；不干预：保持浏览器默认行为

把域名解析经 HTTPS 发往可信解析器，防止同一网络里的人明文窃听你访问的域名或用污染应答把你引向钓鱼站。自动：能加密则加密；强制：全部走加密解析。仅允许 https 且拒绝指向本机/内网/元数据地址的服务器

某个标签的渲染进程崩溃或内存不足时自动重新加载一次；反复崩溃则改为横幅提示，由你手动刷新，避免崩溃循环

直接打开网页或跳转时，自动去除 utm_source、fbclid、gclid 等仅用于广告归因、对页面内容无意义的参数；不影响网址锚点（#）与登录回调

在网页输入框中检查拼写错误，右键错词可查看本地词典给出的替换建议或加入自定义词典；检查完全在本机完成，不会上传你输入的内容

网页请求唤起 mailto: / tel: 等本机协议、且你勾选了“记住选择”时，会按网站记录在这里。其它协议（ms-*、smb、file 等）始终直接拦截，不会产生任何授权
